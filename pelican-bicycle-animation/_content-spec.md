# 设计 spec · 鹈鹕骑自行车 2D 动画

> 这份 spec 是三套逻辑（秒数轮盘 / 现实参照 / 最佳设计师）的**唯一共同输入**。
> 三版方向板只看这份 spec 独立工作，互不参考。

## 1. 产出是什么

一句话：**一只鹈鹕，骑着一辆自行车，在画面里真的把它骑起来。**

- 类型：单镜头循环动画（loop），不是带解说的长片
- 媒介：**用户明确指定 SVG 绘制**——矢量手绘是这次的任务本身，不是「没图可用来糊弄」的降级。
  因此「禁止用 SVG 手画 imagery」这条 anti-slop 规则在此**被用户显式请求覆盖**，
  补偿手段是：解剖学必须站得住（见 §5），不能是「通用鸟形」。
- 尺寸：**1920×1080**，固定画布，letterbox 自适应缩放，三版统一
- 时长：单版 6-8 秒无缝循环（三版节奏不同，是角色性格的一部分）
- 交付形态：单文件 HTML，双击即开（`file://`），零外部依赖、零 CDN、零网络字体

## 2. 受众与场景

用户在本地终端里说一句「帮我生成 html」，要的是一件**能立刻打开、能截图发人、
让人觉得「这玩意儿挺厉害」的小玩意儿**。观看距离是 60-80cm 的笔记本屏幕，
观看时长 10-30 秒，重复观看概率高（循环动画天然被反复看）。
所以：**第一眼要抓人，第十眼经得住看**——经得起看的部分只能来自细节与力学正确性，
不能来自特效。

## 3. 核心信息与内容要点

这个题材在流行文化里有一个非常硬的锚点：**「鹈骑自行车」是著名的「AI 能不能画
会动的荒诞组合」测试题**（Chrome 早年那支「Pelican Airlines」广告把这个梗变成了
一个真实存在的宇宙）。所以核心信息不是「画只鸟骑车」，而是：

1. **荒诞前提 + 严肃执行** = 全部的笑点来源。前提有多不合理，力学就要有多认真。
2. 观众要在 1 秒内认出「鹈鹕」（不是鹭、不是鹳、不是火烈鸟）→ **喉囊**是唯一
   决定性特征，必须是画面主角之一。
3. 观众要相信「它真的在蹬」（不是站在车上滑行）→ 脚踏曲柄与蹼足必须严格耦合。
4. 要留一个「值得截图」的 120% 细节（其他做到 80% 就行）。

## 4. 情感基调与气质关键词

**死面瘫式的认真（deadpan）**。鹈鹕自己不觉得这有任何好笑之处——它是在执行日常通勤。
关键词：笨拙、庄重、通勤感、物理可信、手作的温度、一点点固执。

反面清单（绝不能有的气质）：可爱萌系（Q版大头娃娃）、科技蓝紫、赛博霓虹、
「AI 生成的通用插画」、儿童绘本贴纸。

## 5. 解剖学事实（画错了就一眼假）

鹈鹕区别于其他涉禽的事实，逐条要落到画面上：

- **喉囊（gular pouch）**：下喙之间的巨大皮囊，容量可达十余升，兜鱼后垂在喙下。
  → 本作的**视觉母题**：喉囊当货舱使用（里面装着鱼 / 地图 / 公文包），
  并且它是全片唯一有**惯性滞后**的柔性体，是节奏感的来源。
- **喙**：极长（约占体长 1/3）、直、上喙尖端有钩。不是鹭那种锥状尖喙。
- **腿与足**：腿**极短**、靠身体后下方，四趾全向前并**全蹼相连**（不是鸭的三前一后）。
  → 这是喜剧核心：**腿太短，够不着脚踏**，所以车架必须被改成低跨式；
  蹼足踩脚踏接触面很大、脚踝几乎不弯。
- **可见的「向后弯的关节」不是膝盖**，是踝；真正的膝藏在羽毛里几乎看不见。
  → 画的时候膝向前顶、踝在外侧，这个反直觉的细节是「懂行」的信号。
- **颈**：飞行/骑行时收缩成 S 形，不像鹭那样伸直。站立时粗壮前倾。
- **身**：桶状、重、胸肌厚；尾短。翅尖（初级飞羽）在白色种类上是**黑色**——
  这是白鹈鹕最强的识别色块。
- **头**：相对身体小，头顶有短冠羽；眼小、眼下裸皮。

## 6. 自行车事实

- 两轮同径；**脚踏中轴（BB）略低于轮毂**；曲柄长度决定蹬踏圈直径。
- **滚动接触**：车轮转角与地面前进距离必须严格耦合（v = ωR），
  否则看起来是「在跑步机上原地转」。三版都要做这个耦合，且曲柄→轮转要按齿比换算。
- 链条、牙盘、飞轮、座管、上管、下管、后叉、坐墩、把立、弯把——结构不能少件。
- 骑行者的髋→BB 距离与曲柄长共同决定膝关节的折叠范围，IK 必须可解（不能拉伸穿帮）。

## 7. 输出格式与尺寸（三版必须一致）

- 画布 1920×1080，`viewBox` 一致，骑手在画面中的**占幅比例**接近（约画面高度 62-70%）
- 帧率：JS `requestAnimationFrame` + 手写 `render(t)` 纯函数式驱动
- 必守技术约束（见 skill `references/animation-pitfalls.md`）：
  - 第 0 帧是完整初始状态，`lastTick = null` sentinel，`__ready` 在 tick 首帧配对设置
  - 检测 `window.__recording === true` 时强制不 loop
  - 循环必须在整数倍齿比处闭合（路面 tile 宽度由总位移反推，保证无缝）
  - 画面内**禁止伪 chrome**：不许画进度条、时间码、章节计数、底部署名条
  - 字体只用本机已确认可用的族（不依赖网络），中文后备 Hiragino Sans GB / STHeiti

## 8. 已知约束

- 无任何品牌方，**不取 logo**；鹈鹕是内容主题不是品牌
- 不出现 emoji 作图标；不用紫渐变；不用「深蓝底 + 霓虹 glow」
- 三版**布局骨架必须结构性互异**（不是换色换字体）
- 每版交付时写一句「form 来自内容的哪里」

## 9. 图片需求判断（Phase 3.5）

判定：**图片非必需，且不该取真图。** 这是一支动画、一个虚构角色的动作循环，
真实鹈鹕照片会把它变成图文卡片而不是 motion design。anti-slop 的「内容型主题先取真图」
在此不适用——用户指定的媒介就是矢量手绘。取真图反而违背指令。

## 10. 视觉母题假设（form 的种子）

**喉囊即货舱 / 腿短即障碍。** 鹈鹕骑自行车这个内容里独有的、别的主题不会有的一样东西，
是「一张巨大而柔软的皮囊挂在脸上，而它正用一双几乎够不着脚踏的、全蹼的短腿蹬车」。
所以 form 必须围绕两件事组织：**喉囊的滞后摆动**（节奏与柔体感）与
**腿长与曲柄的紧张关系**（力学与笑点）。任何一版如果没把这两件事做成画面主角，
就是在套模板而不是在做这个题材。
